# 📚 Biblioteca William Wallace - PWA

Aplicación desarrollada con Blazor WebAssembly para la gestión de libros en una biblioteca escolar.

---

## 🚀 Tecnologías utilizadas

- Blazor WebAssembly (.NET)
- C#
- Bootstrap
- PWA (Progressive Web Application)

---

## 🎯 Objetivo del proyecto

Desarrollar una aplicación CRUD que permita:

- Registrar libros
- Listar libros
- Actualizar libros
- Eliminar libros

Además, la aplicación debe funcionar como PWA, permitiendo su instalación como aplicación de escritorio.

---

## 📦 Funcionalidades principales

### 📌 CRUD de libros
- Crear libros con validación de datos
- Listado dinámico de libros
- Edición de registros existentes
- Eliminación de libros

---

### 🎨 Interfaz moderna con Bootstrap
- Formularios estilizados
- Botones con colores semánticos
- Alertas visuales:
  - 🟢 Agregar
  - 🟡 Actualizar
  - 🔴 Eliminar
- Diseño responsive

---

### ⏳ Preload (Spinner de carga)
- Simulación de carga en operaciones:
  - 3 segundos para crear/actualizar
  - 2 segundos para eliminar
- Mejora la experiencia de usuario

---

### 📱 PWA (Progressive Web App)
La aplicación está preparada como PWA:

- Instalación como aplicación de escritorio
- Funcionamiento offline (según configuración del navegador)
- Experiencia similar a app nativa
